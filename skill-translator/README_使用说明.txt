=========================================
Antigravity 技能说明全自动汉化工具
=========================================

这是一个纯本地、完全离线、具备前瞻性的自动化汉化工具，专门用于翻译 Antigravity 插件里的技能说明。

【文件结构】
1. translate.ps1   : 一键汉化脚本。右键点击它，选择“使用 PowerShell 运行”即可开始翻译。
2. restore.ps1     : 一键还原脚本。如果你想恢复系统原版的英文说明，运行它即可无损还原。
3. dictionary.json : 本地字典核心库。所有汉化的文本都存放在这里。
4. backup/         : 安全备份文件夹。第一次运行汉化时会自动生成，用于存放原始文件。

【如何保持前瞻性？(如何支持未来的新技能)】
由于 Antigravity 会不断更新，你以后可能也会安装甚至自己创建新的技能插件。
这个工具完全支持未来的扩展！

当你发现界面里出现了新的英文技能（比如名字叫 `my-new-skill`），你只需要：
1. 用记事本（或代码编辑器）打开 `dictionary.json`。
2. 按照原本的格式在里面新加一行，例如：
   "my-new-skill": "这是我自己写的一个全新的中文说明测试！"
   （请注意 JSON 文件的基本格式：除了最后一行外，每行的末尾必须有一个英文逗号 `,`）。
3. 保存文件。
4. 再次运行 `translate.ps1`。

脚本会自动读取你的新字典，去系统底层精准拦截这个新技能，并把它的说明无缝替换为你写的中文！所有操作都在本地完成，无需调用任何在线 API，永不失效。
